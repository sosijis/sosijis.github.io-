# sosijis.github.io-

- `index.html` — страница чата ("флуд")
- `space.html` — [Путешествие по Солнечной системе](./space.html): гид по планетам, ключевым фактам и истории освоения космоса
- `game/` — [Тактический штурм](./game/README.md): топ-даун шутер на чистой Java (дым, флешки, молотовы, спецназ против террористов, 6 режимов, 5 карт, процедурный звук)

## Запуск игры

```bash
cd game
./run.sh
```

Нужен только JDK 17+ — внешних зависимостей нет.
