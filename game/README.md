# Тактический штурм — Sosijis Tactical Assault

Топ-даун тактический шутер на чистой Java (Swing/AWT, Java2D). Без движков и внешних
зависимостей: вся графика рисуется процедурно, все звуки синтезируются в рантайме.

```
./run.sh          # собрать и запустить
make run          # то же через make
java -jar shooter.jar
```

Нужен JDK 17 или новее (проверено на OpenJDK 21).

---

## Что внутри

### Бой и баллистика

* **Хитскан с пробитием.** Пуля идёт лучом сквозь мир и теряет урон на каждом
  препятствии: бетон почти не пробивается (8 % урона проходит), кирпич — 22 %,
  дерево — 62 %, фанерный ящик — 48 %, металлический — 18 %. У каждого ствола свой
  запас пробития (`penPower`), и когда он кончается, пуля останавливается.
* **Падение урона по дистанции** — после `falloffStart` урон убывает экспоненциально,
  но не ниже 32 %.
* **Броня и шлем.** Бронежилет поглощает часть урона в зависимости от бронебойности
  оружия и сам изнашивается. Попадание в голову даёт ×4 урона, шлем защищает от него.
* **Отдача с паттерном.** Первые выстрелы уводят ствол вверх, дальше добавляется
  горизонтальный «зигзаг» — как у автоматов в тактических шутерах. Прицел игрока
  уводит вместе со стволом и плавно возвращается.
* **Разброс** зависит от стойки: бег хуже стойки, присед точнее в два раза,
  оптика почти убирает разброс. Ослепление и горение точность ухудшают.
* **Разрушаемость.** Стекло, заборы, деревянные стены и ящики выбиваются огнём,
  красные бочки детонируют и накрывают всё вокруг.

### Снаряжение

| Граната | Поведение |
|---|---|
| **Осколочная** | Взрыв с затуханием по расстоянию; за стеной урон режется до 35 %. Запал можно «поварить», удерживая кнопку. |
| **Светошумовая** | Ослепление считается от дистанции, от того, смотрел ли боец в сторону вспышки, и есть ли прямая видимость. Экран белеет, в ушах звенит, боты теряют точность. |
| **Дымовая** | Разрастается из девяти «пузырей», полностью перекрывает линию обзора в обе стороны (и для ботов тоже) и тушит огонь. |
| **Молотов** | Детонирует от удара, разливается очагами по проходимым клеткам, поджигает и наносит урон по времени. Гасится дымовой. |

ПКМ бросает гранату подкидом на короткую дистанцию, ЛКМ — на полную.

### Оружие

23 ствола: ножи, пистолеты (Glock, USP, P250, Desert Eagle, R8), пистолеты-пулемёты
(MP5-SD, MP9, MAC-10, UMP-45, P90), дробовики (Nova, XM1014), винтовки (Galil, FAMAS,
AK-47, M4A4, AUG, SG 553), снайперские (SSG 08, AWP, SCAR-20) и пулемёт M249.
У каждого свои урон, темп, магазин, время перезарядки, отдача, бронебойность,
множитель скорости передвижения, цена и звук. Часть стволов доступна только одной
из сторон.

### Режимы

* **Закладка бомбы** — раунды, экономика, C4, точки A/B, разминирование (10 с,
  5 с с набором сапёра), выпавшая бомба подбирается.
* **Спасение заложников** — освободить и довести до зоны эвакуации; заложника
  можно случайно застрелить и потерять деньги.
* **Командный бой** — бесконечные респавны, играем до лимита фрагов.
* **Каждый за себя** — все против всех, случайный набор оружия после каждой смерти.
* **Гонка вооружений** — 19 ступеней от Glock до ножа, за каждое убийство следующая.
* **Оборона от волн** — спецназ против волн заражённых, каждая волна быстрее и живучее.

### Боты

Спецназ и террористы (плюс заражённые в режиме обороны) с состояниями
`ADVANCE / ENGAGE / COVER / INVESTIGATE / BLIND / FLEE_FIRE / OBJECTIVE`:

* видят конусом обзора с проверкой прямой видимости — дым им мешает так же, как игроку;
* слышат шаги и выстрелы (громкость шага зависит от покрытия и от того, идёт боец
  или крадётся), запоминают последнюю известную позицию и идут проверять;
* ищут укрытие, из которого их не видно, стрейфят, держат дистанцию под свой ствол,
  стреляют очередями с паузами и перезаряжаются в безопасный момент;
* кидают гранаты по ситуации, проверяя, что в точку броска не попадут свои;
* выбегают из огня, слепнут от флешки, закупаются на старте раунда по своим деньгам;
* ходят по A* с сглаживанием пути и штрафом за прижимание к стенам, с защитой от застревания.

Четыре уровня сложности меняют точность, время реакции, дальность обзора и
охоту пользоваться гранатами.

### Карты

Пять карт с разной геометрией и материалами: `de_dust_lite`, `de_office`,
`cs_warehouse`, `de_village`, `ar_arena`. На каждой есть спавны обеих сторон,
зоны закупки, точки закладки A и B, заложники и зона эвакуации — поэтому любой
режим играется на любой карте. Карты собираются кодом в `MapLibrary`
через простой конструктор прямоугольников `MapBuilder`.

### Графика

Тайловый мир с псевдообъёмом (верхняя грань стен смещается от центра экрана),
тени, декали крови и следов от пуль, гильзы с высотой отскока, трассеры,
динамические вспышки выстрелов, объёмный дым, огонь на радиальных градиентах,
зерно и виньетка.

**Туман войны** — полигон видимости строится лучами (число лучей настраивается),
учитывает стены *и* дым, вне конуса остаётся периферийная зона в 130 единиц.

Настройки графики: пресет качества (низкое/среднее/высокое/ультра), разрешение,
полный экран, лимит FPS, сглаживание, туман войны и качество обзора, динамический
свет, тени, объёмный дым, плотность частиц, следы крови и пуль, тряска экрана,
зерно, миникарта, цифры урона.

### Звук

Ни одного звукового файла — всё синтезируется при запуске и микшируется
собственным микшером поверх `SourceDataLine`:

* выстрелы собираются из шумового щелчка с фильтрами, низкочастотного удара и
  короткого эха — у каждого класса оружия свой характер;
* шаги отличаются по покрытию (бетон, металл, доски, трава, песок, вода);
* взрывы, флешка, шипение дыма, треск огня, звон стекла, писк C4, крики, интерфейс;
* фоновая музыка — процедурный луп на 32 шага (бас, пэд, бочка, хэт);
* позиционный звук: панорама и затухание по расстоянию, приглушение за стенами,
  звон в ушах после взрыва рядом, мягкий лимитер, чтобы плотный бой не хрипел.

Если звуковое устройство недоступно, игра сообщает об этом и продолжает работать без звука.

## Управление

| Клавиши | Действие |
|---|---|
| `W A S D` | движение |
| Мышь | прицеливание |
| ЛКМ | огонь |
| ПКМ | оптика / короткий бросок гранаты |
| `R` | перезарядка |
| `1` `2` `3` | основное · пистолет · нож |
| `4` | гранаты (повторное нажатие — следующая) |
| `5` | C4 |
| `Q` | предыдущее оружие |
| `Shift` | тихий шаг |
| `Ctrl` / `C` | присед |
| `E` | заложить · разминировать · освободить заложника · подобрать оружие |
| `B` | меню закупки (в зоне закупки) |
| `Tab` | таблица счёта |
| `Esc` | пауза |
| `F11` | полноэкранный режим |

Аргументы командной строки: `--fullscreen`, `--windowed`, `--map=de_office`,
`--bots=12`, `--low`, `--ultra`.

Настройки сохраняются в `~/.sosijis-shooter/settings.properties`.

## Проверка

```
make test     # безоконный прогон: 6 режимов × 5 карт, с рендером в BufferedImage
make shots    # снимки меню и боя в shots/
```

`make test` гоняет каждую комбинацию режима и карты по 25 игровых секунд вместе с
отрисовкой и падает с ненулевым кодом, если где-то вылетело исключение.

```
src/com/sosijis/shooter/

  Game                      ядро матча: сущности, баллистика, взрывы, видимость
  GameMode                  фазы раунда + шесть режимов
  Actor, Player, Bot        боец, управление, ИИ
  Weapon, WeaponType        каталог оружия и состояние ствола
  Grenade, SmokeCloud, FireArea, Bomb, Hostage, Pickup
  GameMap, Tile, MapBuilder, MapLibrary, Pathfinder
  Renderer, Camera, Fx, Hud, Menu, Ui
  Sfx                       синтез звука и микшер
  Settings, Input, Vec2, MathUtil
tools/com/sosijis/shooter/
  SmokeTest, Shots, UiSmoke проверочные прогоны
```
